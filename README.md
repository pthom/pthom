### Hi, I'm Pascal

I build tools that make code readable and science easy to play with.

**[Dear ImGui Bundle](https://github.com/pthom/imgui_bundle)**: Python and C++ GUIs for desktop, web and phones, built on Dear ImGui.

![PyPI downloads](https://img.shields.io/pypi/dm/imgui-bundle)

Used in research, robotics and 3D: [Genesis](https://github.com/Genesis-Embodied-AI/genesis-world), [Isaac Lab](https://github.com/isaac-sim/IsaacLab), [Newton](https://github.com/newton-physics/newton), [pygfx](https://github.com/pygfx/pygfx), [fastplotlib](https://github.com/fastplotlib/fastplotlib), [DIPY](https://github.com/dipy/dipy), [splatviz](https://github.com/Florian-Barthel/splatviz), and more than 300 other projects.

Try it in your browser, no install: the [Explorer](https://imgui-bundle.pages.dev/explorer/), the [Python playground](https://imgui-bundle.pages.dev/playground/), and the [ImGui Explorer](https://pthom.github.io/imgui_explorer) (linked from Dear ImGui's README).

**Other projects**

- [Hello ImGui](https://github.com/pthom/hello_imgui): Dear ImGui apps for desktop, mobile and web, from one codebase.
- [Fiatlight](https://github.com/pthom/fiatlight): turn Python functions into interactive apps, in one line.
- [litgen](https://github.com/pthom/litgen): Python bindings for C++, readable and IDE-friendly.
- [ImmVision](https://github.com/pthom/immvision): an immediate image debugger.

**Before open source**

I co-founded Interactif Visuel Système (IVS) in 1996 and led its R&D until 2021. We built measuring devices for opticians: Activisu, and Visioffice for Essilor. Image processing, computer vision, biometrics, hardware. The company grew from 3 people to about 100, and was acquired by Essilor.
